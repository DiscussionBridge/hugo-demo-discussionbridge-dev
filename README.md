# DiscussionBridge Hugo Demo

See Discourse discussions on a Hugo site served as static files. The checked-in project uses Hugo adapter version `0.2.0-alpha.20`.

[Open the site](https://hugo.demo.discussionbridge.dev/) · [DiscussionBridge for Hugo](https://github.com/DiscussionBridge/hugo-discussion-bridge) · [All demos](https://demo.discussionbridge.dev/)

## Preview the source

```sh
npm ci
npm run build:preview
```

and deployment records.
